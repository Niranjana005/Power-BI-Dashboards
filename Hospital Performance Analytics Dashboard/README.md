# 🏥 Hospital Performance Analytics Dashboard

An interactive Power BI dashboard developed to analyze hospital performance, patient demographics, revenue, billing, admissions, and recovery trends. The dashboard provides business insights through KPIs, interactive filters, and visual analytics.

---



## 📌 Project Overview

This project focuses on transforming healthcare data into meaningful business insights using Power BI. It enables users to monitor hospital performance, identify trends, and analyze key healthcare metrics through an interactive dashboard.

---

## 🎯 Dashboard Features

- 📊 Total Patients
- 💰 Total Revenue
- 💳 Average Billing Amount
- 🏥 Average Length of Stay
- 🚑 Emergency Admissions
- ✅ Recovery Rate
- 📈 Monthly Patient Admission Trend
- 🏥 Top 10 Hospitals by Revenue
- 🩸 Average Billing by Blood Group
- 🩺 Patient Distribution by Medical Condition
- 👨‍⚕️ Gender Distribution
- 📋 Admission Type Analysis
- 🎛 Interactive Hospital & Age Category Filters

---

## 🛠 Tools & Technologies

- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

---

## 📊 Key Insights

- Analyzed patient distribution across multiple medical conditions.
- Identified the highest revenue-generating hospitals.
- Tracked monthly patient admission trends.
- Compared average billing across different blood groups.
- Evaluated emergency admissions and recovery rate.
- Measured average length of stay by medical condition.
